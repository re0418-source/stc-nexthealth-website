# STC NextHealth｜官網內部展示版

本專案為 STC NextHealth 品牌網站視覺概念與內容溝通版本，使用 HTML、CSS 與 JavaScript 建立。

## 預覽網站

https://re0418-source.github.io/stc-nexthealth-website/

## 本地查看

下載整份專案，在瀏覽器開啟 `index.html`。

## 網站組成

- `index.html`：繁體中文首頁
- `styles.css`：品牌視覺與響應式樣式
- `script.js`：手機版選單
- `assets/`：品牌及產品圖像素材

> 僅供內部提案審閱，非正式購物網站。商品資訊及研發宣稱須經核定後上線。
